# BBA Auction Comparison System

Integration between BBOAlert, BBA Server, and Practice-Bidding-Scenarios for comparing bridge auctions.

## Project Overview

This system allows users to compare actual bridge auctions played on BBO (Bridge Base Online) with "correct" auctions generated by the EPBot bidding engine. The convention cards used for generating auctions are data-driven from the Practice-Bidding-Scenarios project.

## Components

### 1. BBA Server (`/BBA-CLI/bba-server/`)

ASP.NET Core web service that:
- Wraps EPBot64.dll bidding engine
- Provides HTTP API for auction generation
- Reads convention cards from PBS `.dlr` files
- Supports API key authentication

### 2. BBOAlert Plugin (`/bbo-pbs/Plugins/BBAcompare.js`)

Chrome extension plugin that:
- Collects deal data from BBO DOM
- Sends requests to BBA server
- Displays side-by-side auction comparison
- Manual trigger via "Compare Now" button

### 3. Practice-Bidding-Scenarios (`/Practice-Bidding-Scenarios/`)

Source of truth for:
- Scenario definitions (`.dlr` files)
- Convention card specifications (`# convention-card:` property)
- Convention card files (`.bbsa` files)

## Convention Card Lookup

The BBA server reads convention cards from PBS `.dlr` files:

```
# Example from /PBS/dlr/Smolen.dlr
# convention-card: 21GF-DEFAULT
```

**Lookup logic:**
1. If scenario name provided → read `# convention-card:` from `.dlr` file
2. If not specified or not found → use default: `21GF-DEFAULT`
3. EW (opponents) always use: `21GF-GIB`

## Setup Instructions

### 1. BBA Server Setup (Windows)

```bash
cd /BBA-CLI/bba-server
dotnet build
dotnet run
```

Configure `appsettings.json`:
```json
{
  "ApiKey": "your-secret-key",
  "Pbs": {
    "DlrPath": "P:\\dlr",
    "BbsaPath": "P:\\bbsa"
  }
}
```

### 2. BBOAlert Plugin Setup

Add to your BBOalert data file:
```
Javascript,https://github.com/your-repo/bbo-pbs/blob/master/Plugins/BBAcompare.js
```

Configure in BBOalert settings:
- `BBA_Server_URL`: `http://your-server:5000`
- `API_Key`: Your API key
- `Scenario_Name`: Optional (e.g., "Smolen")
- `Enable_Comparison`: Check to enable

### 3. Usage

1. Open BBO teaching table or kibitz with all hands visible
2. Complete an auction
3. In BBOalert settings, check "Compare Now"
4. View comparison in popup panel

## Limitations

1. **Hand visibility**: All 4 hands must be visible (teaching tables, kibitzing, reviewing)

2. **Convention matching**: BBA uses EPBot's interpretation of conventions, which may differ from how humans actually play

3. **Windows requirement**: EPBot64.dll is a Windows COM library - server must run on Windows

4. **Network latency**: HTTP request to server adds some delay

## API Reference

### POST /api/auction/generate

**Request:**
```json
{
  "deal": {
    "pbn": "N:A653.Q97.K64.954 KQ4.AT8432.A72.A J8.K.QJ98.KJT762 T972.J65.T53.Q83",
    "dealer": "S",
    "vulnerability": "NS"
  },
  "scenario": "Smolen",
  "conventions": {
    "ns": "21GF-Puppet"
  }
}
```

**Response:**
```json
{
  "success": true,
  "auction": ["1C", "Pass", "1S", "2H", "..."],
  "auctionEncoded": "1C--1S2H...",
  "conventionsUsed": {
    "ns": "21GF-DEFAULT",
    "ew": "21GF-GIB"
  },
  "meanings": [
    {"position": 0, "bid": "1C", "meaning": "12-21 HCP, 3+ clubs"}
  ]
}
```
