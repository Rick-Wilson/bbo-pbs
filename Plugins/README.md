# Plugins

Plugins are user configurable scripts. To install a plugin, include in your BBOalert data the following record:

    Javascript,https://github.com/stanmaz/BBOalert/blob/master/Plugins/pluginName.js

Note: The stanmazPlugin is included in the latest version of BBOalert.

## Available Plugins

### BBAcompare.js - Auction Comparison

Compares actual BBO auctions with "correct" auctions generated by the BBA (EPBot) bidding engine.

**Features:**
- Manual "Compare Now" button trigger
- Collects deal data from BBO (hands, dealer, vulnerability, auction)
- Sends request to BBA server with optional scenario name for convention lookup
- Displays side-by-side comparison panel with differences highlighted
- Draggable popup panel

**Installation:**

**Method 1 - With PBS (recommended):**
Copy this URL and use Paste (New) in BBOalert:
```
https://github.com/bridge-craftwork/bbo-pbs/blob/master/Plugins/PBS-with-BBAcompare.txt
```
This loads the full PBS system plus the BBA Compare plugin.

**Method 2 - Standalone (without PBS):**
Add this line to your BBOalert data:
```
Javascript,https://github.com/bridge-craftwork/bbo-pbs/blob/master/Plugins/BBAcompare.js
```

**Configuration:**

After loading the plugin, configure in BBOalert settings panel under "BBA Auction Comparison":

| Setting | Description |
|---------|-------------|
| `Enable_Comparison` | Master toggle to enable/disable the plugin |
| `BBA_Server_URL` | URL of the BBA server (e.g., `http://your-server:5000`) |
| `API_Key` | API key for server authentication |
| `Scenario_Name` | Optional scenario name (e.g., "Smolen") for convention card lookup |
| `Compare_Now` | Check this to trigger a comparison |

**Requirements:**
- All 4 hands must be visible (teaching tables, kibitzing, or reviewing)
- BBA Server must be running and accessible

**Usage:**
1. Play or review a hand on BBO with all hands visible
2. After the auction ends, check "Compare Now" in the plugin settings
3. A popup panel shows the comparison:
   - Green header = auctions match
   - Red header = auctions differ
   - Yellow rows = bids that differ
   - Bid meanings from EPBot shown in rightmost column

### PBNcapture.js - PBN Export

Captures deals and auctions from BBO and exports them in PBN format.

### autoRedeal.js - Auto Redeal

Automatically redeals hands on teaching tables.

### stanmazPlugin.js - Stan's Plugin

Various utilities (included in main BBOalert).
